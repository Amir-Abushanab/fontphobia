# Surprises / gotchas

- `rsbuild preview`'s fallback also answers **missing assets** (a `.woff2` or `.js`) with 200 HTML. A crawler that checks font fetches must check `content-type`/magic bytes, not the status.
- There's no `index.html` in the project. Head tags live in `rsbuild.config.ts` `html.tags`/`html.title` (or a custom `html.template`), so a source-level head parser must read the config.
- Raising `dataUriLimit` doesn't just inline fonts: it also moves the fontsource CSS into the `k.<hash>.css` split chunk. Don't assume the font CSS is `index.*.css`.
- Rspack hooks are a valid post-HTML point for an SPA: `done` runs once after emit. `api.onAfterBuild` runs after that and also gives the environment names.
- Plain Rspack woff2 output loses the subset names (`<hash>.woff2`), so mapping files to fontsource subsets has to go through the CSS `@font-face` `unicode-range`, not filenames.
- `create-rsbuild` now ships `octane-*` and `tanstack-start-*` templates, which are a different profile from this SPA.
