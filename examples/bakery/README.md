# Little Levain

The example site from the [walkthrough](https://amir-abushanab.github.io/fontphobia/): four static pages that self-host Inter (the full variable WOFF2) and Fraunces (Google's Latin subset), the way many small sites do. Both fonts are under the SIL Open Font License (`fonts/*-LICENSE.txt`).

To follow along, copy this folder somewhere outside the repository and run fontphobia in it:

```sh
cp -R examples/bakery /tmp/little-levain && cd /tmp/little-levain
pnpm dlx fontphobia
```
